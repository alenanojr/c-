2. C# OOP — from zero

Shortcut: Class = blueprint. Object = actual thing. Property = data. Method = action. Constructor = setup kapag gumagawa ng object.

Class → Object → Property → Method → Constructor

public class Employee
{
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Salary { get; set; }

    public Employee(int id, string name, decimal salary)
    {
        Id = id;
        Name = name;
        Salary = salary;
    }

    public decimal GetAnnualSalary()
    {
        return Salary * 12;
    }
}

Employee employee = new Employee(1, "Alberto", 30000m);
Console.WriteLine(employee.Name);
Console.WriteLine(employee.GetAnnualSalary());
Encapsulation

Control kung paano naa-access o nababago ang internal data.

private string _status;
public string Status => _status;

public void SetStatus(string value)
{
    if (!string.IsNullOrWhiteSpace(value))
        _status = value;
}

Idea: hindi lahat dapat public.

Inheritance
public class Sensor { }
public class TemperatureSensor : Sensor { }

Ang child class ay nagmamana ng behavior/data mula sa parent.

Polymorphism
public interface INotifier
{
    void Send(string message);
}

class EmailNotifier : INotifier
{
    public void Send(string message) { }
}

class SmsNotifier : INotifier
{
    public void Send(string message) { }
}

Same interface, different implementation.

Abstraction

Ipakita ang kailangan gamitin, itago ang internal complexity.

public interface ISerialService
{
    Task SendAsync(string message);
    event Action<string>? MessageReceived;
}
Interface

Contract. Kapag sinabi mong INotifier, anumang class na implements nito ay dapat may Send().

Composition

“Has-a” relationship. Halimbawa: EmployeeService has an IEmployeeRepository.

public class EmployeeService
{
    private readonly IEmployeeRepository _repo;
    public EmployeeService(IEmployeeRepository repo)
    {
        _repo = repo;
    }
}

4. LINQ — search/filter/sort C# collections


LINQ = query syntax for collections. Very useful sa ViewModel, Service, and EF Core.


var softwareEmployees = employees
    .Where(e => e.DepartmentId == 2)
    .OrderByDescending(e => e.Salary)
    .Select(e => e.Name)
    .ToList();


Most useful operators
  • Where — filter
  • Select — transform
  • OrderBy / OrderByDescending — sort
  • FirstOrDefault — first match or null
  • Any — may match ba?
  • Count — count
  • GroupBy — group data
  • ToList — materialize
Live filter


Remember: LINQ is not a database. With an in-memory List, LINQ runs in C#. With EF Core, many LINQ expressions are translated into SQL by the provider.







5. Async / await, Task, threads, errors




Why?
WPF has a UI thread. Kapag doon mo ginawa ang slow API/database/file operation, puwedeng mag-freeze ang window.
private async Task LoadAsync()
{
    var data = await service.GetEmployeesAsync();
    Employees = new ObservableCollection<Employee>(data);
}


Basic terms
  • Task = asynchronous operation
  • async = method can await
  • await = wait without blocking the thread in the normal async flow
  • Dispatcher = return to WPF UI thread when needed




Serial → background event → UI
SerialPort.DataReceived
       ↓
parse / validate in service
       ↓
ViewModel property update
       ↓
Dispatcher / synchronization
       ↓
WPF DataGrid / TextBlock


Common mistakes
  • Blocking UI with .Result or .Wait() in UI code
  • Updating WPF controls directly from a background serial event
  • Ignoring exceptions in async methods
  • Starting unlimited tasks without cancellation/backpressure

    11. STM32 → C# UART/USB Serial Protocol Lab
    

    Key idea: Serial communication is a stream of bytes. Hindi guaranteed na isang buong message ang matatanggap sa isang event.
    

    Example protocol
    TX: READ_TEMP\n
RX: TEMP:28.5|7F\n

Possible frame:
HEADER | PAYLOAD | CHECKSUM | TERMINATOR

Need to think about:
- buffer
- terminator / packet length
- checksum or CRC
- timeout
- retry
- ACK / NACK
- invalid message handling

    18. Interview Cheat Sheet
    

    

    What is C#?
    “C# is a programming language commonly used on the .NET platform. I use it to model data, write business logic, services, and desktop application code.”
    

    What is WPF?
    “WPF is a Windows desktop UI framework on .NET. XAML describes the UI and C# handles application behavior.”
    

    What is MVVM?
    “MVVM separates View, ViewModel, and Model. Binding connects the View to ViewModel state, while commands handle UI actions.”
    

    Why ObservableCollection?
    “It raises collection-change notifications so bound WPF controls can reflect additions and removals.”
    

    Why interface?
    “An interface defines a contract. It lets me swap implementations and makes services easier to test with mocks.”
    

    Why async/await?
    “To avoid blocking the UI during I/O such as API, database, or file operations.”
    

    How do you debug?
    “I reproduce the issue, isolate the failing layer, inspect logs/breakpoints, test a hypothesis, fix the root cause, then retest.”
    

    You don't know STM32 deeply?
    “My stronger experience is software, but I understand the communication flow and core peripherals. I would be transparent about my current level and learn the team's HAL/CubeIDE workflow quickly.”
    

    

    Never memorize only the words. Understand the flow and explain it using one simple example: Employee Management or Temperature Monitoring.
